🌟 LingBot-World 2.0 핵심 기술 아키텍처

♾️

무한 상호작용 (Unbounded Horizon)

인과적(Causal) 사전학습 패러다임과 동적 KV 캐시 스케줄링을 통해 메모리 폭발이나 드리프트 왜곡 없이 끝없는 세계를 탐험합니다.

⚡

초고속 응답 (Real-Time Distillation)

13억 파라미터(1.3B)와 14B Causal-Fast 증류 모델로, 단일 GPU(RTX 6000 Ada)에서 1스텝당 1.6초 디노이징을 달성했습니다.

🎬

디렉터-파일럿 에이전트 하네스

VLM(비전-언어 모델)이 '감독(Director)'이 되어 거시적 사건을 계획하고, Causal DiT가 '조종사(Pilot)'가 되어 물리적 비디오를 실시간 렌더링합니다.

🎮

Plücker 카메라 광선 주입

OpenCV 3D 좌표계 기준의 카메라 회전 및 이동 벡터를 Plücker 광선 임베딩으로 인과적 트랜스포머에 주입하여 완벽한 시점 제어를 보장합니다.

💻 로컬 실행 가이드 (Quick Start)

저장소를 클론하고 아래 명령어를 실행하면, 브라우저에서 즉시 실시간 탐험을 즐길 수 있습니다:

# 1. 저장소 이동 및 가상환경 활성화 cd lingbot-world-v2 # 2. 실시간 인터랙티브 Web UI 실행 python app.py --host 0.0.0.0 --port 7860 # 3. 브라우저에서 접속: http://localhost:7860
